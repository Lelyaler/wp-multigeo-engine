# WP MultiGEO & Satellite Engine

Профессиональный модуль WordPress для мультирегионального SEO, клонирования посадочных страниц и дифференцированного управления мета-тегами Canonical и Hreflang для сеток сайтов-сателлитов (PBN) в высококонкурентных нишах (iGaming, медиа, affiliate-маркетинг).

## Проблема, которую решает плагин

При продвижении проектов в различных регионах и двух основных поисковых системах (Google и Яндекс) вебмастера сталкиваются со следующими сложностями:
1. **Разные требования к каноникализации**: Google требует перенаправлять ссылочный вес главной страницы на конкретную региональную копию (`canonical -> /kz/`), в то время как Яндекс негативно реагирует на склейку и требует раздельного индексирования.
2. **Конфликты коробочных SEO-плагинов**: Yoast SEO и RankMath принудительно навязывают собственные каноникалы, ломая региональные связки.
3. **Рутинная ручная синхронизация**: при изменении лендинга приходится вручную переносить текст, миниатюры и десятки полей ACF Pro на региональные страницы.
4. **Безопасность удаленного управления**: сеткам требуется удаленный доступ для переключения ГЕО без раскрытия учетных записей администратора.

## Архитектура и возможности

- **Модульная ООП-структура**:
  - `MultiGeo_Bot_Detector` — точная идентификация поисковых краулеров (Googlebot, YandexBot, Bingbot) по User-Agent.
  - `MultiGeo_Page_Replicator` — безопасное автоматическое клонирование главной страницы с переносом метаданных, структуры ACF Pro и шаблонов.
  - `MultiGeo_Seo_Manager` — динамическая генерация `canonical` (дифференцированно для Googlebot и YandexBot), тегов `hreflang` (ISO-стандарт) и атрибута `lang` в теге `<html>`.
  - `MultiGeo_Rest_Api` — защищённые эндпоинты для внешней автоматизации с авторизацией по токену `X-API-Key`.
  - `MultiGeo_Admin` — панель управления в светлых тонах WordPress Core Admin UI.
- **Нейтрализация конфликтов**:
  - Автоматическое подавление дублирующих тегов canonical от Yoast SEO, RankMath и All in One SEO на целевых страницах.
- **Безопасность**:
  - Полная Nonce-защита интерфейса (`wp_nonce_field`, `check_admin_referer`);
  - Авторизация REST API через криптографически стойкий `X-API-Key` заголовок (`hash_equals`).

## Использование REST API

### 1. Обновление целевого слага и ГЕО
```bash
curl -X POST "https://example.com/wp-json/multigeo/v1/update-target" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_SECRET_API_KEY" \
  -d '{
    "target_slug": "ca",
    "target_geo": "en-ca"
  }'
```

### 2. Получение текущего статуса
```bash
curl -X GET "https://example.com/wp-json/multigeo/v1/status" \
  -H "X-API-Key: YOUR_SECRET_API_KEY"
```

## Установка

1. Скопируйте папку `wp-multigeo-engine` в директорию `/wp-content/plugins/`.
2. Активируйте плагин через меню **Плагины** в панели администратора WordPress.
3. Перейдите в **Настройки -> MultiGEO Engine** для задания целевого слага и ГЕО-кода.
